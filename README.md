#### ✨ 核心设计

* 🧠 **活人感 NPC，有底线拒迎合**  
  NPC 拥有独立动机与利益边界，会试探、犹豫、拒绝甚至在离开视线后自主行动，绝非千篇一律的顺从附和。
* 🔓 **自带 18+ 破甲，深度语境脱敏**  
  告别机械拒绝与出戏说教，直面冲突博弈、利益对峙与细腻饱满的成人情感，文字考究、张力十足而不露骨。
* 🌐 **52 套现成世界库，上千项素材咬合**  
  涵盖盛唐夜市、幕末京都、芝加哥黑帮、赛博边缘、都市暗流等，时代风土与微观动作深度咬合，每次开局都是新故事。
* ⏳ **世界自行运转，全维原点续玩**  
  时间自然流逝，离屏事件按时推演；采用轻量 YAML 状态机持久化，多分支自由存档，长线剧情不失忆。
