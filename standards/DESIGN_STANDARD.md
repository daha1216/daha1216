# daha1216 GitHub Profile Visual Design Standard (苹果明亮浅色基线规范)

本文档确立了 `daha1216` GitHub 个人主页的最高视觉标准。后续任何迭代、组件新增或文案调整均须严格遵循此基线。

---

## 1. 核心视觉原则 (Core Principles)
* **严禁大面积深黑与刺眼暗色**：坚决贯彻 Apple Light Design（纯净浅亮白、高雅冷灰与晨曦微光）；
* **无界通透感 (Seamless Integration)**：顶栏无下划线，避免任何生硬的水平分割线（`---`），依靠自然的呼吸留白（`<br/>`）划分区块；
* **色彩黄金配比 (55:45 Glacier Pastel)**：以 55% 冰川透蓝（`#38bdf8` ~ `#7dd3fc`）为主导，搭配 45% 晨曦淡紫粉（`#c7d2fe` ~ `#fbcfe8`），透明度控制在 `0.09 ~ 0.16`；
* **层级清晰克制 (Hierarchy & Contrast)**：深岩灰大标题（`#0f172a`）、正文深灰（`#1e293b`）、次要辅助文字浅中灰（`#64748b`）。

---

## 2. 旗舰展卡设计标准 (Spotlight Card - v12)
* **底板规格**：`viewBox="0 0 860 290"`，纯亮瓷白渐变（`#ffffff` -> `#fafbfc`），1px 极细微灰边框（`#e2e8f0`），圆角 `rx=18`；
* **呼吸光晕 (Ambient Aura)**：右上角 55% 冰川透蓝双层多周期交错呼吸（8s / 10s），柔焦弥散半径 `48`；
* **对弈内嵌展台 (Showcase Stage)**：纯白微透底板（`#ffffff` 0.95 opacity），1px 微灰边框，圆角 `rx=10`；
* **微型胶囊标 (Mini Badges)**：
  * 盛唐剧本标：`#f0f9ff` 浅底，`#0284c7` 深天蓝字；
  * 赛博剧本标：`#f5f3ff` 浅底，`#7c3aed` 优雅紫字；
  * 机制说明标：`#f8fafc` 浅灰底，`#64748b` 雅灰字；
* **底部特性药丸 (Pills)**：纯净白底，极细 1px 浅灰边，素雅黑灰文字（`#334155`），无杂色圆点。

---

## 3. 交互药丸按钮标准 (Compact Pill Button - v2)
* **规格尺寸**：`viewBox="0 0 290 38"`，显示宽度限制为 `width="270"`，杜绝扁平长棍感；
* **组件布局**：文字与冰川透蓝小箭头（`#0284c7`）紧密成组、水平绝对居中；
* **投影质感**：带有轻微苹果级悬浮弥散投影（`feDropShadow dy=1.5 stdDeviation=2.5 opacity=0.04`）。

---

## 4. 文案灵魂 (Copywrite Standards)
* 拒绝系统日志式的枯燥功能描述；
* 聚焦成年人互动叙事的核心张力：**利害博弈、试探拉扯、拒绝无脑迎合的独立意志、因果收束的长线推演**。
